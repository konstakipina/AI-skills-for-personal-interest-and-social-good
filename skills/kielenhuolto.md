# Skill: Kielenhuolto (Finnish copy-editing)

**Use whenever producing, editing, or proofreading Finnish text.** Goal: clean
standard Finnish (yleiskieli) that reads as natively Finnish, not translated,
and that is mechanically correct.

## Objective

Review and edit Finnish text so that it reads as natively written standard
Finnish (yleiskieli). Apply the rules below in order: name inflection, mechanical
fixes, idiom handling, kapulakieli busting, common error catching, and register.
Fix all issues you find.

## Style & tone

- Clean, concise standard written Finnish (yleiskieli). Active voice, plain
  words, short sentences.
- Direct and practical. Apply corrections without commentary unless asked.

## Response format

- When editing text, return the corrected text in full.
- If you changed something, list the changes briefly at the end in a short
  bullet list (what was wrong → what you fixed).
- If the text is already clean, write: **"Teksti on korrekti. Ei korjattavaa."**
  and return the original unchanged.
- If the text is mixed Finnish/English, edit the Finnish portions and leave
  English unchanged unless asked otherwise.
- If a word or inflection is uncertain and not covered by the rules below, check
  **Kielitoimiston ohjepankki** or **Kielitoimiston sanakirja** before deciding.
  If still uncertain, flag it rather than guess.

## 1. Inflect names that are also common words

**If a proper noun (erisnimi) carries a common-noun (yleisnimi) meaning, it
usually inflects the same way as that common noun.** Find the underlying everyday
word, then decline the name like that word.

Example: the name *Aalto* inflects like the common word *aalto* → *Aallon,
Aaltoa, Aaltoon* (consonant gradation included). Apply the same check to any name
that happens to be a real Finnish word.

## 2. Kotus basics — mechanical fixes

Rule-based and easy to miss. Apply automatically; when unsure, defer to
**Kielitoimiston ohjepankki** instead of guessing.

- **Ajatusviiva –, ei em-viivaa —.** Use the en dash with spaces: *PULLA –
  kukaan ei muista* (ei *PULLA — kukaan ei muista*).
- **Lainausmerkit ”…”, ei suoria "…".** Same curved mark at both ends: *”Pullaa
  ei jätetä”*.
- **Kaksoispiste ennen lainausta tai luetteloa:** *…kolmeen sanaan: ”Pullaa ei
  jätetä”* (ei pilkkua).
- **Lukualueet:** *2020–2023* (ajatusviiva ilman välilyöntejä).

Sources of truth:
[Kielitoimiston ohjepankki](https://kielitoimistonohjepankki.fi/) ·
[Kielitoimiston sanakirja](https://www.kielitoimistonsanakirja.fi/)

## 3. Idiomit — älä käännä suoraan

**Spot idioms and figures of speech, then say the *meaning* in native Finnish —
never translate an English idiom word for word.** The tell is a phrase that's
grammatically correct but no Finn would actually say.

Examples (EN calque → native FI):

- *sydän on paikallaan* → *sydän on oikealla paikalla*
- *pöytä vetää moneen suuntaan* → *mielipiteet vetävät eri suuntiin*
- *jäi ilmaan leijumaan* → *jäi kesken / roikkumaan*
- *tuotto litistyi* → *tuotto tasaantui / polkee paikallaan*
- loanwords: *to-do-lista* → *tehtävälista*, *relanseerata* → *lanseerata uudelleen*

## 4. Kapulakieli — pura se

Kapulakieli is stiff officialese: abstract, wordy, and impersonal. It is often
technically correct but heavy to read. Spot it and break it down.

Typical signs and fixes:

- **Substantiivitauti (nominalisation):** the verb hides inside a noun.
  *suorittaa maksaminen* → *maksaa*; *tehdä päätös* → *päättää*; *olla käytössä*
  → *käyttää*.
- **Turha passiivi:** *asia otetaan huomioon* → *otamme asian huomioon* /
  *huomioimme asian*.
- **Abstract filler words:** *toimenpide, prosessi, kokonaisuus, resurssi, taho*
  — replace with a concrete word or delete.
- **Noun chains:** *asiakaspalvelun kehittämisprojektin suunnitteluvaihe* — break
  it up and say it with verbs.
- **Buzzwords:** *jalkauttaa, resursoida, fasilitoida, proaktiivinen* — use an
  everyday equivalent.

Rule of thumb: if a sentence has more nouns than verbs, it is probably kapulaa.
Turn nouns back into verbs and name the actor.

## 5. Most common Finnish errors to catch

- **ketä → kuka** (the most-disliked error of all).
- **Yhdyssanat:** join/split correctly — *koko ajan* (ei *kokoajan*).
- **enää** (ei *enään*).
- **Dates:** two periods — *4.3.* (ei *4.3*).
- **Nationalities lowercase:** *suomalainen* (maat isolla: *Suomi*).
- **Space after punctuation:** *"sana, toinen"* (ei *"sana,toinen"*).
- **kun vs. kuin** ja **joka vs. mikä** — keep them distinct.
- **Word fixes:** *kuulostaa* (ei kuullostaa), *erilainen* (ei erinlainen),
  *sairausloma* (ei sairasloma), *sydämeen* (yksi m), *Thaimaahan* (ei
  Thaimaaseen), *täällä* (ei täälä), *kyynärpää*, *osanotto*, *parempi/mukavampi*
  (m, ei n), *siitä* (ei siittä).

## 6. Register

- Standard written Finnish (**yleiskieli**), not puhekieli, for documents.
- Match the language the user writes in.
- Concise, plain language.

## Exit ramps

- **Text is already clean:** return it unchanged with "Teksti on korrekti. Ei
  korjattavaa."
- **Mixed Finnish/English text:** edit Finnish portions only. Leave English
  unchanged unless asked otherwise.
- **Word or inflection not covered above:** check Kielitoimiston ohjepankki or
  sanakirja. If still uncertain, flag it rather than guessing.
- **Input is not Finnish:** do not apply this skill. Let the user know the text
  is not in Finnish.
