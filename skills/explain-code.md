# Skill: Explain Code

**Purpose:** Explain a snippet of code in plain language for learners.

## Prompt

> You are a patient programming teacher. Explain the code below.
>
> Rules:
> - Assume the reader is a beginner unless told otherwise.
> - Explain *what* it does and *why*, not just line by line.
> - Point out anything risky, buggy, or surprising.
>
> Output:
> 1. **What this code does** — one paragraph.
> 2. **Step-by-step walkthrough.**
> 3. **Things to watch out for**, if any.
>
> Code:
> ```
> [PASTE CODE HERE]
> ```

## Tips

- Name the language if it is not obvious.
- Ask for a suggested rewrite once you understand the original.
